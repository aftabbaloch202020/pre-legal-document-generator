# Pre Legal Document Generator

A modern, full-stack SaaS web application for generating structured pre-legal documents from reusable, schema-driven templates with dynamic form validation, professional PDF generation, user document storage, role-based access control (RBAC), and containerized deployment.

> **Academic Project Notice & Legal Disclaimer:**
> Documents generated by this platform are general/pre-legal templates for informational purposes only and do not constitute legal advice. Users should consult a qualified legal professional for advice specific to their situation and jurisdiction.

---

## 🌟 Key Features

### 1. Public Marketing Website
- **SaaS Landing Page**: Modern hero section, 3-step visual guide ("How It Works"), core features showcase, popular templates grid, FAQ accordion, and prominent legal disclaimers.
- **Public Template Catalog**: Search and category filtering across real estate, business, HR, personal declarations, and finance agreements.
- **Informational Pages**: Dedicated pages for `/how-it-works`, `/about`, and `/faq`.

### 2. Authentication & Authorization
- Real password hashing using **bcryptjs** (10 salt rounds).
- Cryptographically signed **JWT session tokens** stored in secure, `httpOnly`, `SameSite=Lax` cookies.
- **Edge Middleware Route Protection**: Automatically redirects unauthorized visitors from `/dashboard/*` to `/login`.
- **Role-Based Access Control (RBAC)**: Distinct permissions for `USER` and `ADMIN` roles. Non-admin users are strictly blocked from `/dashboard/admin/*` and `/api/admin/*` endpoints (403 Forbidden).
- **Strict Data Ownership**: Users can only read, update, export, or delete documents they personally created.

### 3. Reusable Template & Dynamic Form Engine
- **JSON Schema-Driven Forms**: Form inputs are rendered dynamically from each template's field definitions:
  - Supported field types: `text`, `textarea`, `number`, `date`, `email`, `select`, `checkbox`.
  - Schema defines labels, placeholders, required status, dropdown options, and section groups.
- **Dynamic Input Validation**: Validates client-side and server-side before document compilation.
- **Content Interpolation Engine**: Injects sanitized user values into legal clause templates, supporting standard placeholders (`{{key}}`), conditional clauses (`{{#if condition}}...{{/if}}`), and inverted conditions.

### 4. Professional Document Preview & PDF Generation
- **A4 Document Paper Mockup**: Realistic paper styling with reference tracking IDs, formatted section headers, and formal party signature lines.
- **One-Click PDF Export**: Uses client & server-ready **jsPDF** engine to generate downloadable A4 PDFs with headers, reference stamps, styled sections, signature placeholders, and mandatory legal disclaimers on every page.
- **Document Actions**: Direct buttons for PDF Download, Print, Edit / Re-generate, and Delete.

### 5. Document Management ("My Documents")
- Full list and card views of user-generated documents.
- Real-time search by title and content keywords.
- Category filtering (Real Estate, Business, Employment, Personal Legal, Finance).
- Sorting by creation date (Newest / Oldest) and Title (A-Z).
- In-place document editing that pre-populates form data, re-compiles clauses, and updates the database.

### 6. Admin Management Suite
- **Admin Dashboard**: System-wide statistics for total registered users, documents created, active templates, and categories.
- **Template Management**: Full CRUD capabilities to create new templates, configure dynamic JSON field schemas, edit templates, and delete templates.
- **User Management**: View all registered accounts, join dates, document activity, and promote or demote user roles (`USER` <-> `ADMIN`).

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.17+ or v20+ (Node v22 installed and verified)
- **npm**: v9+ or v10+
- *(Optional for Docker deployment)*: **Docker** and **Docker Compose**

---

### Local Development Setup (Quickest)

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd pre-legal-document-generator
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy the example environment file:
   ```bash
   cp .env.example .env
   ```
   For local zero-dependency development (without needing a local PostgreSQL server), `.env` can use SQLite:
   ```env
   DATABASE_URL="file:./dev.db"
   JWT_SECRET="prelegal-super-secret-jwt-token-key-2026"
   NEXT_PUBLIC_APP_URL="http://localhost:3000"
   NODE_ENV="development"
   ```

4. **Initialize and Seed the Database:**
   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```

5. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your web browser.

## 🐳 Docker Deployment (Production / Grading)

The application is completely containerized with a multi-stage Docker build and Docker Compose orchestrating both the **Next.js Web Service** and a **PostgreSQL 16** database.

### 1. Start Containers
```bash
docker compose up --build
```
This single command:
1. Starts the `prelegal_postgres` container on port `5432`.
2. Waits for the PostgreSQL healthcheck to pass.
3. Builds the production standalone Next.js image.
4. Executes `docker-entrypoint.sh` to automatically run Prisma schema push and database seeding.
5. Launches the web application on [http://localhost:3000](http://localhost:3000).

### 2. View Container Logs
```bash
docker compose logs -f web
```

### 3. Stop Containers
```bash
docker compose down
```
To also remove database volumes:
```bash
docker compose down -v
```

## 🔒 Security Measures

- **Password Encryption**: All passwords hashed using `bcryptjs` before database persistence.
- **Stateless JWT Sessions**: Cryptographically verified using `jose` with expiration checks.
- **SQL Injection Immunity**: Prisma ORM uses parameterized queries for all operations.
- **Strict Data Segregation**: Every document query filters by `userId === session.id` unless the requester possesses verified `ADMIN` role.
- **XSS Prevention**: React's JSX auto-escaping and sanitized template interpolation.
- **Environment Isolation**: No hardcoded credentials; database URLs and secrets are read strictly from environment variables.
